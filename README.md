# LiteLoad — The Cheap Phone Test

A beginner-friendly, lightweight website prototype built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. Click **Run quick device check**.

## Files
- `index.html` — page structure
- `style.css` — responsive mobile-first styling
- `app.js` — basic browser hint display
- `LiteLoad_Cheap_Phone_Test_Prototype.pptx` — prototype presentation

## Publish source code on GitHub
1. Sign in at https://github.com/
2. Click **New repository**.
3. Name it `LiteLoad-Cheap-Phone-Test`.
4. Set it to Public if your event permits public repositories.
5. Upload the files in this folder (or use GitHub Desktop).
6. Copy the repository URL and paste it into the submission form.

## Record a demo video
1. Open `index.html` in your browser.
2. Start a screen recording using Windows Snipping Tool (Screen recording) or another approved recorder.
3. Show the page at desktop width, resize to a narrow mobile-like width, and click **Run quick device check**.
4. Save the recording and upload it where the event asks, or provide its hosted URL.

## Honest scope
This is a prototype/demo, not a validated benchmark. It does not measure actual load-time improvements or guarantee compatibility with every low-end device. Test on real devices and report observed results.
